# 主程序入口模块

## 模块概述

本模块是钉钉直播回放下载工具的程序入口，负责协调各子模块的工作，提供用户交互界面，并管理整个下载流程。

## 功能描述

### 核心功能

1. **程序启动与初始化**

   - 显示欢迎信息和版本号
   - 初始化日志系统
   - 获取用户选择的下载模式

2. **单个视频下载模式**

   - 获取用户输入的钉钉直播回放链接
   - 支持选择保存模式（默认路径/手动选择）
   - 支持选择浏览器类型（Edge/Chrome/Firefox）
   - 调用下载器执行下载
   - 支持继续输入新链接进行下载

3. **批量下载模式**

   - 获取用户输入的文件路径（CSV/Excel）
   - 读取文件中的多个链接
   - 支持选择保存模式和浏览器类型
   - 批量调用下载器执行下载
   - 支持继续输入新文件进行批量下载

4. **异常处理**
   - 捕获用户中断（Ctrl+C）
   - 捕获并记录其他异常
   - 优雅退出程序

## 核心实现原理

### 程序流程

```
程序启动
  ↓
初始化日志系统
  ↓
显示欢迎信息
  ↓
获取下载模式选择
  ↓
┌─────────────┬─────────────┐
│ 单个下载模式 │ 批量下载模式 │
└─────────────┴─────────────┘
  ↓              ↓
获取链接        读取文件
  ↓              ↓
创建下载器      创建下载器
  ↓              ↓
执行下载        批量下载
  ↓              ↓
继续/退出       继续/退出
```

### 关键设计

1. **模块化设计**

   - 通过导入各子模块实现功能解耦
   - 使用 `Downloader` 类统一管理下载流程

2. **用户交互**

   - 使用 `input()` 函数获取用户输入
   - 使用 `validate_input()` 函数验证输入有效性

3. **日志记录**
   - 在关键步骤记录日志
   - 使用异常处理记录错误信息

## 使用方法

### 直接运行

```bash
python -m dingtalk_downloader.main
```

### 交互流程

1. 启动程序后，选择下载模式（1：单个视频，2：批量下载）
2. 根据选择的模式，输入相应的信息
3. 等待下载完成
4. 可选择继续下载或退出程序

## 接口参数说明

### 函数：single_mode()

**功能**：单个视频下载模式

**参数**：无

**返回值**：无

**用户输入**：

- `dingtalk_url`：钉钉直播回放分享链接
- `save_mode`：保存模式（1：默认路径，2：手动选择）
- `browser_option`：浏览器选项（1：Edge，2：Chrome，3：Firefox）

**异常**：

- `KeyboardInterrupt`：用户中断
- `Exception`：其他异常

### 函数：batch_mode()

**功能**：批量下载模式

**参数**：无

**返回值**：无

**用户输入**：

- `file_path`：文件路径（CSV/Excel）
- `save_mode`：保存模式（1：默认路径，2：手动选择）
- `browser_option`：浏览器选项（1：Edge，2：Chrome，3：Firefox）

**异常**：

- `KeyboardInterrupt`：用户中断
- `Exception`：其他异常

### 函数：main()

**功能**：主程序入口

**参数**：无

**返回值**：无

**用户输入**：

- `download_mode`：下载模式（1：单个视频，2：批量下载）

**异常**：

- `KeyboardInterrupt`：用户中断
- `Exception`：其他异常

## 数据流程

### 单个下载模式数据流

```
用户输入链接
  ↓
用户选择保存模式
  ↓
用户选择浏览器类型
  ↓
创建 Downloader 实例
  ↓
调用 download_single_video()
  ↓
下载完成/继续/退出
```

### 批量下载模式数据流

```
用户输入文件路径
  ↓
FileReader 读取链接
  ↓
用户选择保存模式
  ↓
用户选择浏览器类型
  ↓
创建 Downloader 实例
  ↓
调用 download_batch_videos()
  ↓
批量下载完成/继续/退出
```

## 注意事项

1. **用户输入验证**

   - 所有用户输入都通过 `validate_input()` 函数验证
   - 支持默认选项（直接按 Enter）

2. **异常处理**

   - 捕获 `KeyboardInterrupt` 实现优雅退出
   - 捕获其他异常并记录日志

3. **日志记录**

   - 在关键步骤记录日志
   - 异常时记录完整堆栈信息

4. **资源释放**
   - 程序退出时自动释放资源
   - 使用 `sys.exit(0)` 或 `sys.exit(1)` 退出
