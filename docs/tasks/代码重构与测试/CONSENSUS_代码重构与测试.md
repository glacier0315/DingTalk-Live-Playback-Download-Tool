## 二、技术实现方案

### 2.1 重构技术方案

#### 2.1.1 模块划分方案

**目标结构**：
```
src/dingtalk_downloader/
├── __init__.py
├── main.py                          # 程序入口
├── core/                            # 核心业务逻辑
│   ├── __init__.py
│   ├── downloader.py                 # 下载器核心
│   ├── cookie_handler.py            # Cookie 处理
│   └── m3u8_parser.py               # m3u8 解析
├── utils/                           # 工具函数
│   ├── __init__.py
│   ├── file_reader.py               # 文件读取
│   ├── validator.py                 # 输入验证
│   └── path_helper.py               # 路径处理
├── binary/                          # 二进制程序调用
│   ├── __init__.py
│   ├── n_m3u8dl_re.py               # N_m3u8DL-RE 调用
│   └── ffmpeg_wrapper.py           # FFmpeg 调用
├── browser/                         # 浏览器自动化
│   ├── __init__.py
│   ├── browser_factory.py           # 浏览器工厂
│   ├── edge_driver.py               # Edge 驱动
│   ├── chrome_driver.py             # Chrome 驱动
│   └── firefox_driver.py            # Firefox 驱动
└── config/                          # 配置管理
    ├── __init__.py
    ├── settings.py                 # 配置项
    └── constants.py                 # 常量
```

**模块职责**：

1. **main.py**：程序入口，协调各模块
2. **core/downloader.py**：下载器核心逻辑，协调 Cookie 获取、m3u8 解析、视频下载
3. **core/cookie_handler.py**：Cookie 处理逻辑，获取和管理 Cookie
4. **core/m3u8_parser.py**：m3u8 解析逻辑，提取 m3u8 链接和基础 URL
5. **utils/file_reader.py**：文件读取工具，从 CSV/Excel 读取链接
6. **utils/validator.py**：输入验证工具，验证用户输入
7. **utils/path_helper.py**：路径处理工具，处理文件路径
8. **binary/n_m3u8dl_re.py**：N_m3u8DL-RE 调用封装
9. **binary/ffmpeg_wrapper.py**：FFmpeg 调用封装
10. **browser/browser_factory.py**：浏览器工厂，创建浏览器实例
11. **browser/edge_driver.py**：Edge 浏览器驱动
12. **browser/chrome_driver.py**：Chrome 浏览器驱动
13. **browser/firefox_driver.py**：Firefox 浏览器驱动
14. **config/settings.py**：配置项定义
15. **config/constants.py**：常量定义

#### 2.1.2 代码复用方案

**消除重复代码**：

1. **合并下载函数**：
   - 原有三个下载函数：`download_m3u8_with_options`、`download_m3u8_with_reused_path`、`auto_download_m3u8_with_options`
   - 合并为一个通用下载函数：`download_m3u8_video(m3u8_file, save_name, prefix, cookies_data, headers, save_dir)`
   - 通过参数控制保存路径

2. **提取 Cookie 和请求头添加逻辑**：
   - 提取为独立函数：`build_download_command(m3u8_file, save_name, save_dir, prefix, cookies_data, headers)`
   - 统一命令构建逻辑

3. **使用浏览器工厂模式**：
   - 创建浏览器工厂类：`BrowserFactory`
   - 根据浏览器类型创建对应的浏览器实例
   - 统一浏览器创建逻辑

#### 2.1.3 命名规范方案

**遵循 PEP 8 规范**：

1. **变量名**：小写字母+下划线
   - `browser` → `_browser`（受保护成员）
   - `dingtalk_url` → `dingtalk_url`
   - `cookies_data` → `cookies_data`

2. **函数名**：小写字母+下划线
   - `get_browser_cookie()` → `get_browser_cookie()`
   - `fetch_m3u8_links()` → `fetch_m3u8_links()`
   - `download_m3u8_file()` → `download_m3u8_file()`

3. **类名**：大驼峰命名（PascalCase）
   - `BrowserFactory`、`CookieHandler`、`M3u8Parser`

4. **常量**：全大写+下划线
   - `BROWSER_TYPE_EDGE = 'edge'`
   - `BROWSER_TYPE_CHROME = 'chrome'`
   - `BROWSER_TYPE_FIREFOX = 'firefox'`
   - `MAX_RETRY_COUNT = 5`

#### 2.1.4 注释添加方案

**使用 Google 风格文档字符串**：

1. **模块文档字符串**：
```python
"""
钉钉直播回放下载工具 - 核心业务逻辑模块

本模块包含下载器核心逻辑、Cookie 处理逻辑、m3u8 解析逻辑。

作者：项目团队
依赖：selenium>=4.6.0, pandas
创建日期：2024-12-18
修改历史：
    - 2024-12-18: 初始版本
    - 2025-01-14: 模块化重构
"""
```

2. **类文档字符串**：
```python
class BrowserFactory:
    """
    浏览器工厂类，负责创建不同类型的浏览器实例。

    该类封装了 Edge、Chrome、Firefox 三种浏览器的创建逻辑，
    提供统一的接口供上层模块使用。

    Attributes:
        browser_type (str): 浏览器类型
    """
```

3. **函数文档字符串**：
```python
def get_browser_cookie(url: str, browser_type: str = 'edge') -> tuple:
    """
    获取浏览器 Cookie 和请求头信息。

    通过 Selenium 自动化浏览器访问指定 URL，获取登录后的 Cookie 和请求头信息，
    用于后续的 m3u8 视频流下载。

    Args:
        url: 钉钉直播回放分享链接
        browser_type: 浏览器类型，可选值为'edge'、'chrome'、'firefox'，默认为'edge'

    Returns:
        tuple: 包含四个元素的元组
            - browser: Selenium 浏览器实例
            - cookie_dict: Cookie 字典，格式为 {cookie_name: cookie_value}
            - headers: 请求头字典，包含 User-Agent、Referer 等
            - live_name: 直播视频名称

    Raises:
        Exception: 当浏览器启动失败或获取 Cookie 失败时
        TimeoutException: 当页面加载超时时
    """
```
