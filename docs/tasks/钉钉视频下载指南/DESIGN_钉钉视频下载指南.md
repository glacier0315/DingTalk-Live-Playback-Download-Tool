## 异常处理策略

### 异常分类

1. **用户输入异常**: 链接格式错误、参数缺失
2. **网络异常**: 连接超时、下载失败
3. **鉴权异常**: Cookie过期、auth_key无效
4. **系统异常**: 工具未安装、权限不足

### 处理策略

1. **用户输入异常**: 提示用户重新输入
2. **网络异常**: 自动重试,提示用户检查网络
3. **鉴权异常**: 提示用户重新登录
4. **系统异常**: 提示用户安装必要工具
