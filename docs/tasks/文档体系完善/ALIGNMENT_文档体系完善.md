## 一、项目背景

### 1.1 项目概述

**项目名称**：DingTalk-Live-Playback-Download-Tool（钉钉直播回放下载工具）

**项目描述**：一个基于 Python 的钉钉直播回放下载工具，支持单个和批量下载钉钉直播回放视频。

**技术栈**：

- Python 3.8+
- Selenium（浏览器自动化）
- N_m3u8DL-RE（m3u8 视频流下载）
- FFmpeg（视频处理）
- Pandas（文件读取）

## 三、项目特性规范

### 3.1 代码结构

```
src/dingtalk_downloader/
├── main.py                    # 主程序入口
├── core/                      # 核心业务逻辑
│   ├── downloader.py         # 下载器
│   ├── cookie_handler.py     # Cookie 处理
│   └── m3u8_parser.py        # m3u8 解析
├── utils/                     # 工具函数
│   ├── file_reader.py        # 文件读取
│   ├── validator.py          # 输入验证
│   └── path_helper.py        # 路径处理
├── binary/                    # 二进制程序调用
│   ├── n_m3u8dl_re.py        # N_m3u8DL-RE
│   └── ffmpeg_wrapper.py     # FFmpeg
├── browser/                   # 浏览器自动化
│   ├── browser_factory.py    # 浏览器工厂
│   ├── edge_driver.py        # Edge 驱动
│   ├── chrome_driver.py      # Chrome 驱动
│   └── firefox_driver.py     # Firefox 驱动
└── config/                    # 配置管理
    ├── settings.py           # 配置项
    └── constants.py          # 常量
```

### 3.2 核心模块

**Downloader**：下载器，负责协调各模块完成下载任务

**CookieHandler**：Cookie 处理器，负责获取和管理 Cookie

**M3u8Parser**：m3u8 解析器，负责解析 m3u8 文件

**FileReader**：文件读取器，负责从 CSV/Excel 文件中读取链接

**NM3u8DLRE**：N_m3u8DL-RE 调用器，负责调用 N_m3u8DL-RE 工具

**BrowserFactory**：浏览器工厂，负责创建浏览器实例

### 3.3 技术特性

**浏览器支持**：Edge、Chrome、Firefox

**下载模式**：单个下载、批量下载

**保存模式**：默认路径、手动选择

**文件格式**：CSV、Excel

**视频格式**：m3u8 视频流
